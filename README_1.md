# REPCO ROSTER

Full roster system - username only, all data through Firebase.

## Structure
- `/index.html` - Main roster app
- `/rmroster/index.html` - Same app for subpath
- `/src/pages/Register.jsx` - Username-only registration
- `/src/pages/Login.jsx` - Username-only login

## Firebase: https://repco-roster-default-rtdb.firebaseio.com

## Menus by Role
Staff: ROSTER, SHIFT OFFERS, TODAY'S BUDDIES, TOMORROW'S BUDDIES, MY SCHEDULE, ACCOUNT, LOG OUT
Manager/Admin: ALL

## Deploy
Upload all files to repo root, enable Pages: main branch / root
